# DSSSB CS Practice Studio

Tablet-friendly practice app for DSSSB TGT Computer Science preparation.

## Included
- 834 worked questions in 148 sections, with shortcuts and explanations.
- 232 additional pattern-practice questions.
- 216 structured MCQs are automatically scored; other questions use explicit self-check ratings.
- Timed sets, spaced revision, bookmarks, personal notes, a 30-day plan, dark mode and progress backups.
- 37 original official paper files, indexed as 8,100 paper-and-question entries.
- 27 supplied source documents (1,411 pages) prepared as 59 reading files/parts.

Progress and personal notes stay in the browser. Use Settings to export/import a backup. PDF caching is optional per file, so the entire library is not downloaded automatically.

## Install on Android
Open the GitHub Pages URL in Chrome, then menu → Add to Home screen / Install app, if offered. Wait for the core practice bank to be ready offline. Save any needed PDFs from the library while online.

## Source limitations
The archive preserves original printed answer keys and diagrams; it is not a separately validated explanation of all 8,100 entries. Supplied books and handwritten notes remain reference material. Dated facts and disputed keys need checking. The 41/26 detailed subject mapping provisionally uses the supplied 56/24 syllabus.

This app and the supplied PDFs are published publicly at the owner's explicit request. No API key or backend is needed.
